About

A modern jailbreak detection bypass. Shadow hides the jailbreak from apps on a per-app basis, with hook profiles you can tune in Settings → Shadow.

This build is maintained by erv5 as a fork; upstream credit and original work by jjolano.

Compatibility

  • Rootless (Dopamine, palera1n rootless): iphoneos-arm64
  • RootHide (Serotonin / RootHide bootstrap): iphoneos-arm64e

Dependencies

Requires HookKit, AltList, and libSandy — all declared as dependencies and hosted on this repo, so they install automatically with Shadow. No extra sources needed.
